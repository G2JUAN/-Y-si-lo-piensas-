Actualización 1.0.0

v1.0.0

En este espacio puedes observar las actualizaciones hechas en el blog ¿Y si lo piensas?

+ Implementado

  • Se incorporaron varias opciones de cuestionarios: Opcion multiple, Escrita, Mixta
  • Se incorporo un sistema de login para poder ingresar a la pagina web
  • Se añadio el tema faltante: Relaciones Sexuales Casuales
  • Se implemento un nuevo menu para poder elegir cualquier cuestionario sin entrar al tema en especifico

✓ Arreglado

  • Se mejoró la distribución del contenido en cualquiero tipo de resolucion, tamaño de ventana y moviles
  • Se arreglo la falla en las redirecciones al finalizar los cuestionarios de opcion multiple
  • Se optimizaron las animaciones de los textos, imagenes, scroll y etc...

− Quitado

  • Se retiraron pies de paginas no importantes con el objetivo de darle mas claridad a la pagina web
  • Se eliminaron elementos visuales
